# Floral Boutique & Fragrance Agency Landing Page

A multi-section landing page built with semantic HTML5 and custom CSS3 (`style.css` alongside Font Awesome 5 styles in `all.css`), designed around floral arrangements, bouquets, and fragrance themes.

## Project Structure & Key Files
* `index.html`: Main landing page markup containing the top navigation bar, hero banner, introductory feature cards, featured floral works gallery, services overview, "why choose us" section, statistics banner, pricing plans, team and testimonial sections, recent news cards, and footer[cite: 4].
* `style.css`: Custom stylesheet defining layout rules, overlays, hover transitions, card grids, and section styling[cite: 6].
* `all.css`: Font Awesome Free (`5.15.4`) stylesheet and icon class definitions[cite: 5].
* `images/`: Referenced floral, nature, portrait, and gallery image assets[cite: 4, 6].

## Page Sections & Features
* **Header & Navigation Bar:** Fixed top bar featuring a spa/flower icon, search input box, navigation links (`home`, `about`, `portfolio`, `services`, `prices`, `team`, `blog`, `contact Us`), and a hover dropdown submenu under `blog` (`scents history`, `ingredients`, `celebrity Picks`)[cite: 4, 6].
* **Hero Section:** Full-viewport banner (`We are creative agency`) with dark overlay, introductory text, and `get started` / `learn more!` action buttons[cite: 4, 6].
* **Welcome & Highlights Cards:** Three feature cards highlighting natural scents, daily touch, and fragrance appeal with hover fill animations[cite: 4, 6].
* **Featured Works Gallery:** Six-item grid displaying flower and nature photography (`images/`) with hover overlay captions and action icons[cite: 4, 6, 7, 8, 10, 11, 12, 13].
* **What We Offer & Why Choose Us:** Six service cards (`fresh floral`, `custom bouquets`, `Same-Day Delivery`, `Indoor Plants`, `International Delivery`, `Event Decor`) followed by a two-column value proposition section with checklist items and a side image[cite: 4, 6].
* **Statistics, Pricing & Team/News:** Metrics banner, three pricing tiers (`Spring Flower`, `ROYAL ROSE`, `ROSE BOUQUET`), team/testimonial blocks, recent news cards, and a footer with social icons[cite: 4, 6].

## Built With
* **HTML5**[cite: 4]
* **CSS3** (`style.css`)[cite: 6]
* **Icons:** Font Awesome (`5.15.4` via `all.css`)[cite: 4, 5]

## How to Run
1. Keep `index.html`, `style.css`, `all.css`, and the `images/` folder in their expected relative paths[cite: 4, 5, 6].
2. Open `index.html` in any web browser (or run it using a local server such as VS Code **Live Server**)[cite: 4].
