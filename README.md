# Petal & Bloom — Floral Boutique Landing Page

A multi-section front-end website concept for a floral boutique, built with HTML5 and CSS3. The page explores a complete marketing-site layout, from the hero and gallery to services, pricing, team, news, and footer sections.

## Highlights
- Multi-section landing page with anchored navigation and a dropdown menu.
- Hero banner, feature cards, and floral image gallery.
- Service cards, pricing layouts, team profiles, and news cards.
- Hover overlays and transitions using custom CSS.
- Local Font Awesome assets and image folder.

## Tech Stack
- HTML5
- CSS3
- Font Awesome 5 (local stylesheet and webfonts)

## Run Locally
1. Clone this repository.
2. Keep the css/, images/, and webfonts/ folders alongside index.html.
3. Open index.html in a browser or use VS Code Live Server.

## Project Notes
- This is a front-end design exercise, not a deployed commercial flower shop.
- Navigation links scroll to sections within the page.
- Pricing, statistics, testimonials, and team details are illustrative content.
- No shopping cart, payment processing, or backend is included.

## Repository Structure
- index.html — page structure and content.
- css/style.css — custom layout and responsive styling.
- css/all.css and webfonts/ — local Font Awesome assets.
- images/ — visual assets used by the page.
